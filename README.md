# DavidsonTech Academy 🎓

DavidsonTech Academy is a modern e-learning web application built with **React** and **Tailwind CSS**, focused on delivering structured tech education through a clean, responsive, and user-friendly interface.

The platform includes authentication, course pages, dashboards, and pricing flows, following real-world frontend architecture and best practices.

---

## 🚀 Features

- User Authentication (Sign up, Login, Password reset)
- User Dashboard
- Course listing & course detail pages
- Pricing & lifetime access pages
- Responsive design for desktop and mobile
- Reusable component-based UI
- Clean and scalable folder structure

---

## 🛠 Tech Stack

- **React**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **Firebase / Supabase** (authentication & backend services)
- **Git & GitHub**


## 📁 Project Structure

src/
├── components/ # Reusable UI components (Navbar, Footer, Cards, etc.)
├── pages/ # Application pages (Home, Courses, Dashboard, Auth pages)
├── context/ # Global state & authentication context
├── lib/ # Configuration files & helpers
├── App.js
└── index.js
